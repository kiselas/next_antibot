# Antispam Bot

Антиспам-бот для Telegram-группы на **Python 3.14 + python-telegram-bot v22**.
Анализирует сообщения новых участников нейросетью через **OpenRouter**; при вердикте
«спам» — удаляет сообщение и применяет санкцию (бан/мьют/только отчёт). Управление,
статистика и разбор ложных срабатываний — в личке бота.

## Как это работает

```
Сообщение в группе
      │
      ▼
Чат разрешён? (ALLOWED_CHAT_IDS) ── нет ─► игнор (бот выходит из чужих чатов)
      │ да
      ▼
Автор доверенный / админ / в белом списке? ── да ─► пропустить
      │ нет
      ▼
Пре-фильтр (короткое без ссылок?) ── да ─► пропустить (не тратим квоту)
      │ нет
      ▼
LLM-классификатор (OpenRouter) ─► {is_spam, confidence, reason}
      │
      ├─ спам, confidence ≥ порога ─► удалить + санкция (action_mode) + лог
      ├─ не спам ─► +1 к «чистым»; после N сообщений автор становится доверенным
      └─ ошибка LLM ─► fail-safe: ничего не делаем; при серии сбоев — алерт админу
```

- **Доверие.** Новичок проверяется, пока не накопит `trust_after_clean_msgs` чистых
  сообщений или не пробудет в группе `trust_after_hours` часов. Дальше его сообщения
  не идут в LLM. Админы группы/бота и белый список — доверенные сразу.
- **Fail-safe.** При недоступности OpenRouter санкции не выдаются. Если ошибки идут
  подряд (`LLM_ERROR_ALERT_THRESHOLD`) — бот предупредит админа (например, кончились
  кредиты — 402, или троттлинг — 429).
- **Защита от prompt injection.** Текст сообщения передаётся модели как недоверенные
  данные в маркерах; инструкции внутри текста игнорируются.
- **Allowlist чатов.** Без `ALLOWED_CHAT_IDS` бот работает везде (с предупреждением);
  со списком — в чужих чатах сам выходит, чтобы не жгли вашу квоту.
- **Резерв моделей.** При ошибке основной модели по очереди пробуются
  `OPENROUTER_FALLBACK_MODELS`.
- **Редактирование сообщений** тоже проверяется (спамер не обойдёт фильтр правкой).

## Подготовка

1. **Создайте бота** у [@BotFather](https://t.me/BotFather), получите `BOT_TOKEN`.
2. **Выключите Privacy Mode:** BotFather → `/mybots` → бот → *Bot Settings* →
   *Group Privacy* → **Turn off**. Иначе бот не видит обычные сообщения.
3. **Добавьте бота в группу администратором** с правами **«Удаление сообщений»** и
   **«Блокировка пользователей»**. (Права админа также нужны, чтобы получать события
   о входе участников.)
4. **OpenRouter:** ключ на <https://openrouter.ai/keys> (`OPENROUTER_API_KEY`).
   Для лимита 1000 запросов/сутки занесите ~$10 кредитов.
5. **Узнайте ID своей группы** (например, через [@getidsbot](https://t.me/getidsbot))
   и впишите в `ALLOWED_CHAT_IDS`. Свой `@username`/ID — в `ADMIN_USERNAMES`/`ADMIN_USER_IDS`.

## Запуск

```bash
cp .env.example .env   # Windows: copy .env.example .env
# заполните .env: BOT_TOKEN, OPENROUTER_API_KEY, ADMIN_USERNAMES, ALLOWED_CHAT_IDS

docker compose up -d --build
docker compose logs -f
```

База SQLite сохраняется в `./data` (том) и переживает перезапуски. В контейнере
работает healthcheck (heartbeat-файл) — статус виден в `docker ps`.

### Локально без Docker

```bash
python -m venv .venv
. .venv/bin/activate          # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements.txt
# для локального запуска задайте в .env свой путь: DB_PATH=./data/bot.db
python -m app.main
```

## Управление (в личке бота, только для админов)

| Команда | Действие |
|---|---|
| `/stats` | Статистика модерации |
| `/recent [N]` | Последние N действий с причиной и текстом (для разбора ложных банов) |
| `/test <текст>` | Прогнать классификатор на тексте без последствий (подбор порога) |
| `/config` | Текущие параметры |
| `/set <ключ> <значение>` | Изменить параметр на лету |
| `/unban <user_id> [chat_id]` | Снять бан/мьют и пометить доверенным |
| `/allow <@user\|user_id>` | Добавить в белый список |
| `/unallow <@user\|user_id>` | Убрать из белого списка |
| `/whitelist` | Показать белый список |
| `/resetstats` | Обнулить статистику |
| `/help` | Справка |

Изменяемые параметры (`/set`):

| Ключ | Что делает |
|---|---|
| `enabled` | Вкл/выкл модерацию (`true`/`false`) |
| `action_mode` | Реакция на спам: `ban` / `mute` / `report` |
| `spam_confidence_threshold` | Порог уверенности для санкции (`0.0`..`1.0`) |
| `trust_after_clean_msgs` | Чистых сообщений до «доверенного» (`0` = выкл) |
| `trust_after_hours` | Часов в группе до «доверенного» (`0` = выкл) |
| `min_chars_for_llm` | Минимум символов для вызова LLM |
| `max_chars_to_llm` | Лимит символов сообщения для LLM |
| `llm_daily_limit` | Дневной лимит обращений к LLM (анти-флуд; `0` = без лимита) |
| `group_topic` | Тематика группы (профильная реклама не считается спамом) |
| `allowed_domains` | Домены, ссылки на которые допустимы (через запятую) |
| `model` | Основная модель OpenRouter |
| `use_json_format` | Запрашивать строгий JSON (часть free-моделей его не умеет) |

Примеры: `/set spam_confidence_threshold 0.9`, `/set action_mode mute`,
`/set model deepseek/deepseek-chat`.

Если задан `ADMIN_CHAT_ID`, отчёт о каждом действии приходит туда с inline-кнопками
**«Разбанить/Размьютить»**, **«Ок»** (а в режиме `report` — **«Забанить»**), чтобы
исправлять решения в один тап. Кнопки доступны только админам бота/чата.

## Ограничения

- Классификация **только по тексту/подписи**. Картинки/стикеры без текста не
  анализируются.
- На строго бесплатном тарифе OpenRouter — лимит 50 запросов/сутки (с $10 кредитов —
  1000/сутки).
- Список бесплатных моделей OpenRouter меняется — при ошибках смените `model`
  (через `/set model <id>`) или `OPENROUTER_FALLBACK_MODELS`.
- `trust_after_hours` считается с момента, когда бот **впервые увидел** участника
  (вошёл при работающем боте-админе либо написал) — не с реального входа, если бот
  ещё не был добавлен/админом.

## Структура

```
app/
  main.py             запуск, builder (rate limiter, concurrency), хендлеры, polling
  config.py           конфиг из .env (pydantic-settings)
  storage.py          SQLite: доверие, журнал, статистика, настройки, белый список
  runtime_settings.py динамические параметры (/set)
  llm.py              клиент OpenRouter + fallback + классификация ошибок
  prompts.py          промпт классификатора (с защитой от инъекций)
  pipeline.py         пре-фильтр -> LLM -> решение
  handlers.py         модерация, участники, админ-команды
tests/                юнит-тесты (pipeline, settings, llm)
```
