# Участие в проекте

Спасибо за интерес к проекту! Любые PR и issue приветствуются.

## Окружение разработки

Требуется Python 3.12+ (рекомендуется 3.14).

```bash
python -m venv .venv
. .venv/bin/activate            # Windows: .venv\Scripts\Activate.ps1
pip install -r requirements-dev.txt
cp .env.example .env            # заполните для локального запуска
```

## Перед коммитом

```bash
python -m py_compile app/*.py   # синтаксис
pytest                          # тесты
```

Новые возможности и исправления логики желательно сопровождать тестами в `tests/`.

## Стиль

- Python: 4 пробела, type hints, докстроки для модулей и нетривиальных функций.
- Комментарии и пользовательские сообщения — на русском (как в существующем коде).
- Не добавляйте тяжёлых зависимостей без необходимости.
- Секреты — только через `.env`; никогда не коммитьте реальные токены/ключи.

## Pull requests

1. Создайте ветку от `main`.
2. Опишите, что и зачем меняется; приложите шаги проверки.
3. Убедитесь, что CI зелёный (компиляция + тесты).
